# AutodocNews

Лента новостей Autodoc.ru для iPhone и iPad.

Новости приходят с `https://webapi.autodoc.ru/api/news`. Список листается по страницам. В карточке обложка и заголовок, по нажатию открывается статья целиком.

## Сверх задания

При запуске проигрывается короткая заставка, нарисованная Metal-шейдером. Если включено уменьшение движения, заставка не покажется.

В ленте есть фильтр: все новости, автомобильные и новости компании.

Картинку в статье можно открыть отдельно и рассмотреть ближе. Это работает и для обложки, и для изображений внутри текста.

Так же добавленна поддержка для iPhone Duo.
